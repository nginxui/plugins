# Code of Conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).

## Our pledge

We want participation in this catalog — submitting a plugin, reviewing one,
filing an issue, or commenting on a pull request — to be a harassment-free
experience for everyone, regardless of experience level, background, or
identity.

## Expected behavior

- Be respectful and constructive, especially in code review and security
  discussions.
- Assume good faith, but verify claims: a plugin submission is reviewed on
  its technical merits (see `CONTRIBUTING.md`), not on trust in the author.
- Disclose security issues responsibly. Do not use a public issue or pull
  request to report a vulnerability in a listed plugin or in the catalog
  tooling itself; see `docs/signing.md` for the contact used for security
  reports.

## Unacceptable behavior

- Harassment, insults, or personal attacks directed at contributors or
  maintainers.
- Submitting a plugin that intentionally misrepresents what it does, hides
  functionality from its manifest, or impersonates another author or vendor.
- Deliberately publishing malicious code, credential-harvesting logic, or
  supply-chain attacks through this catalog.

## Enforcement

Maintainers may remove comments, close issues or pull requests, reject
submissions, or yank a listed plugin (see `CONTRIBUTING.md#yank-procedure`)
that violate this code of conduct or the submission requirements. Repeated or
severe violations may result in the author being blocked from future
submissions.

## Reporting

Report a code of conduct concern by opening a private security advisory on
this repository, or by contacting the maintainers listed in the main
[nginx-ui](https://github.com/0xJacky/nginx-ui) repository.
